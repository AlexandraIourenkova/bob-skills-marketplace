# Pack `presentations` — Presentations that tell a story

Vendor: `ibm` (marketplace team). Original skills written for this marketplace, Apache-2.0. Install with `uvx bob-skills add presentations` or `/skills-add presentations` inside Bob.

From a topic or a spreadsheet to a deck people remember, and to the talk around it. Two decisions stay with the user: the storyline and the visual style.

| Skill | What it does | Scripts |
|---|---|---|
| `presentation` | The whole workflow, in order: brief, story, style, visuals, build, verify, talk kit | `storyboard_check.py` (headline test, bullet limits, missing sources, timing), `deck_build.py` (styled 16:9 .pptx), `deck_html.py` (interactive and printable HTML), `deck_inspect.py` (read the deck back, geometry checks) |
| `deck-story` | Narrative structure by audience and goal, twelve story patterns, six lenses that turn data into three to five findings | `data_profile.py` (columns, ranges, missing values, per-period change) |
| `deck-style` | Five conceptually different style concepts drawn on the deck's own slides, chosen by the user, written as `theme.json` | `style_preview.py` (fifteen concepts, two of them dark, contrast checked, brand colour, Cyrillic, Hebrew and Arabic fonts) |
| `deck-dataviz` | The chart that matches the message, and how to make it readable | `chart_render.py` (waterfall, slope, lollipop, bullet, small multiples, scatter, heatmap in the deck's colours) |
| `deck-images` | Bundled icons and textures, open image sources with their licences, generation prompts, placement | `visual_assets.py` (backdrops in SVG and PNG, 92 Carbon icons, 12 pattern tiles, one treatment for the user's photos, labelled placeholders) |
| `deck-pitch` | Pitch at four lengths, per-slide talk track, Q&A bank with backup slides, one-pager, follow-up email, rehearsal plan | `assets/talk-kit-template.md` |

## One storyboard, three outputs

The storyboard is a Markdown file with one headline per slide. HTML is the default output because it builds in a second and one file carries the whole deck:

```bash
uv run python deck_html.py deck/storyboard.md --theme deck/theme.json -o deck/deck.html
uv run python deck_html.py deck/storyboard.md --theme deck/theme.json --mode static -o deck/print.html
uv run --with python-pptx python deck_build.py deck/storyboard.md --theme deck/theme.json -o deck/deck.pptx
```

The interactive HTML has keyboard and click navigation, an overview grid, speaker notes and a print view; it can be mailed or served by any static host. The static HTML prints to a PDF, one slide per page. The .pptx is for people who will edit or present from Office, and is built on request. Fourteen layouts (title, section, bullets, two columns, big numbers, quote, statement, image, chart, timeline, table, closing, split picture, icon tiles) are chosen from the content unless the storyboard names one.

## The style question

`style_preview.py` writes an HTML page with five concepts drawn on the deck's own title, bullets, chart, big-number and section slides, by the same renderer that builds the deck. The default five are Swiss Minimal, IBM Carbon, Cyber Steel, Pencil Sketch and Geometric Poster; a set never leaves out a dark option. The user picks one, and `--choose <id>` writes `theme.json`, which the .pptx builder, the HTML deck, the chart renderer and the image scripts all read. Each concept has its own ornament, not only its own colours: a column grid for IBM Carbon, HUD brackets for Cyber Steel, pencil hatching for Sketch, circles and triangles for Geometric Poster.

## What ships inside

`skills/deck-images/assets` carries what a deck normally needs, so nothing has to be searched for or licensed per file:

- 86 pictures in eight packs (abstract vector, black and white photo art, dark technology, people at work, paper craft, desk objects, IBM-style isometric, IBM dark premium), generated by the team from the prompts in the pack, about 16 MB in all; `library --for-theme` picks the pack that fits a theme and hands out distinct pictures for the title, the sections and the content. A generated backdrop in the theme colours is offered beside them.
- 92 Carbon icons (IBM, Apache-2.0, one LICENSE and one NOTICE for the whole set, `manifest.json` records the original Carbon name and keywords of each).
- 12 tileable pattern tiles written for this pack.
- Backdrops can also be generated: ten patterns in the theme's colours, SVG for the HTML deck and PNG for the .pptx.

Photographs stay with the user: the skill gives search terms, sources with their licences and generation prompts, then treats and records what the user provides.

## Offline and honest

Every script runs with `uv run --with <library> python <script>`, has `--help`, never touches the network and writes only the path it is given. Pictures are never downloaded: the skills give search terms, sources with licences, or prompts, and record the credits. `rules/presentations.md` fixes the environment and the verification step: read the built deck back, look at the rendered slides, and say what was skipped.
